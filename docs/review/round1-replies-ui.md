# Round 1 replies: UI (UI designer)

- U1 Closed. ALI picked Race Front-End on the direction card. The Android surface brief already records it, and the Windows companion brief now inherits Race Front-End (its path windows/src/Companion.App exists). DESIGN.md and .impeccable/design.json are at the project root.
- U2 Fixed in Controls.kt. pressAndRelease now runs onCancel in a finally block when the gesture is cancelled, the control turns inactive, or it leaves composition. MomentaryButton releases (sends 0) through that path and also through a DisposableEffect, guarded so it fires once. A cancelled tap no longer toggles a LatchingButton or RadioKeys. AxisSlider's drag loop is wrapped in try/finally, so a spring-return slider snaps back to rest even when the drag is cut off. SelectorSwitch and RadioKeys hold no "down" state, so there is nothing to release. The engine releasing everything on lifecycle pause (A2/A3) is still yours.
- U3 Fixed, and confirmed with a 640×360 render (.impeccable/review/play_small.png): three pages, readouts and both links, with Edit fully on screen. Below 720dp the HUD goes "tight": link badges show only the lamp (filled, half or hollow still gives the state, and the full status stays in the accessibility label), rpm is dropped (speed and gear stay), and the profile name is capped at 128dp. Page tabs scroll.
- U4 Fixed. The slider re-syncs through LaunchedEffect(value) and skips while dragging or while a spring-back is already heading to the same value.
- U5 Fixed. Cap labels now show down to 48dp of face height, using the compact unit style between 48 and 64dp.
- U6 Done on the UI side. New ui/screens/LayoutRules.kt adds Control.minSpan(page): a switch or radio needs one cell per position along its long axis, a slider 2 cells along its axis, and a rotary 2×2, all capped to the page. The editor's resize handle and the inspector's Width/Height steppers enforce it. Core still needs the same rule: Profiles.defaultControl should create SWITCH at w=3 (3 positions) and ROTARY at 2×2, and resize/clamp should respect minSpan. The built-in profiles also place 1×1 rotaries (BeamNG "Cruise speed"), which squeezes the knob and makes it spill into the cell below in the editor. Please make them 2×2 or move the rule into core and I'll switch to it.
- U7 Done. GameReadouts(imperial) shows mph, and PlayScreen has a new trailing parameter `imperialUnits: Boolean = false`. Wire it to a settings preference when you have one. Existing calls compile unchanged.
- U8 Fixed. New ui/components/Haptics.kt adds rememberPressHaptic(): HapticFeedbackConstants.CONFIRM on API 30+ (it exists from API 30, not 34), with LONG_PRESS as the fallback. It's used for momentary press, latch toggle and radio pick. Detent ticks stay on TextHandleMove.
- U9 Fixed. While a game, the PC link or Bluetooth HID is connected, Edit needs a long-press. A tap just changes the button to "HOLD" for 1.6s. TalkBack gets the long-press action labelled "Edit layout". With nothing linked, Edit opens on a tap as before. SlantButton gained optional onLongClick and longClickLabel parameters.
- U10 Fixed. RadioKeys goes through rememberUpdatedState like the other controls.
- Also done: ProfilesScreen takes `hid: HidUi` as the third parameter, after `connection`. The header shows the Bluetooth and PC badges together as one 48dp target that opens Connect.
